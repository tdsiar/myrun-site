# MyRun showcase

[Read the website](https://tdsiar.github.io/myrun-site/).

Timothy’s project page describes a C inference rebuild, its debugging lessons, and its evidence.

## Update the website

Edit `index.html` and `style.css`, then push to `main`.
GitHub Pages publishes this directory directly. No build step is needed.

## Local preview

```sh
python3 -m http.server 8000
```

Open http://localhost:8000.
